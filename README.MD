<h1>Escopo do Projeto</h1>
<p>Esse é o repositório do projeto Pequenos Programadores!</p>
Dentro deste projeto, será criado um site de programação que ensinará crianças e pré-adolescentes sobre o básico de informática e programação, preparando-os para suas futuras carreiras.
Será utilizado o método Scrum e Kanban para a gestão do projeto, podendo fazer alterações no que for necessário e revisões para a entrega do projeto.
<h2><strong>Linguagens de programação:</strong></h2>
<ul>*HTML
*CSS
*JavaScript
*SQL Server </ul>
<p>Escopo do projeto:</p>
<p> O projeto incluirá 7 páginas principais, podendo adicionar mais até a data de entrega. Entre elas nós temos:
<ul>*Página inicial
*Página de login
*Página de cadastro
*Página sobre nós
*Página de cursos
*Página de controle dos pais
*Página de termos e condições</p>
<p>Cada uma dessas páginas terá como esqueleto a linguagem HTML e será estilizada pelo CSS. A funcionalidade e incrementações adicionais serão feitas através do JavaScript. O SQL será para registro de novos usuários e resgate do momento do curso onde parou.</p>
<p>Durante a construção do site, teremos uma pessoa para fazer a revisão das funcionalidades e detectar erros e bugs dos códigos com relação à página.</p>

<h2><strong>HTML</strong></h2>
<p>HTML será responsável por toda a estrutura de código (esqueleto) do site.</p>
<p>A partir da codificação em HTML, serão adicionados links, imagens fixas (sobre nós) e interligação com as outras linguagens de programação.
<p> É necessário que todos os códigos sejam separados em divs e tenha descrição para maior organização. ex.: *<*!--titulo*>*</p>.
<h2><strong>CSS</strong></h2>
<p>O CSS será responsável pela estilização do site utilizando as cores da paleta, alinhando textos, imagens e vídeos com precisão.
<p>Sugestão: utilizar código *<*flex*>* para facilitar a exibição na web mobile.</p>
<h2><strong>JavaScript</strong></h2>
O JavaScript será responsável por dar funcionalidades ao site, como o menu hambúrguer, vídeos e imagens com transição, animações, etc.; fornecendo uma página web lúdica e mais interativa com o público.</p>
<p>Estará diretamente ligado com outras linguagens para fazer atualizações em tempo real e facilitar o back-end.</p>
<h2><strong>SQL Server</strong></h2>
<p>Será a linguagem de programação utilizada para a criação de um banco de dados organizado para registro de informações e resgate das mesmas, deixando os novos usuários seguros sem perder as informações e o progresso do curso, enquanto os que desejarem sair poderão excluir sua conta do banco de dados sem precisar acessá-lo diretamente.</p>
<p>Fará conexão direta com o HTML e JavaScript para registro, atualizações e manutenções do sistema.</p>
<h2>Instrução</h2>
<p>Os códigos serão feitos e executados seguindo as instruções da administração, sujeitos a revisão, manutenção, exclusão e criação de um novo projeto. A estilização do site seguirá as instruções (paleta de cores, logo, filmagens, fotos e vídeos) do Marketing.</p>
<p>O prazo máximo de entrega do site será a última quinta-feira antes da apresentação para a banca.</p>
<p>Conto com a ajuda de todos os colaboradores para entregarmos o melhor resultado possível em 3 meses!</p>
