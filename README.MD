<h1>Escopo do Projeto</h1>
<p>Esse é o repositório do projeto Pequenos Programadores!</p>
Dentro deste projeto, será criado um site de programação que ensinará crianças e pré-adolesccentes sobre o básico de informática e progamação, os preparando para suas futuras carreiras.
Será utilizado o etodo Scrum e Kanban para a gestão do projeto, podendo fazer alterações no que for necessário e revisões para a entrega do projeto.
<h2><strong>Linguagens de programação:</strong></h2>
<ul>*HTML
*CSS
*Javascript
*SQL Sever </ul>
<p>Escopo o projeto:</p>
<p> O projeto incluirá 7 páginas principais, podendo adicionar mais até a data de entrega. Entre elas nós temos:
<ul>*Página inicial
*Página de login
*Página de cadasto
*Página sobre nós
*Página de cursos
*Página de controle dos pais
*Página de termos e condições</p>
<p>Cada uma dessas páginas tera como esqueleto a linguagem HTML e será estilizada pelo CSS. A funcionalidade e incrementações adicionais serão feitas através do Javascript. O SQL será para registro de novos usuários e resgate do momento do curso onde parou.</p>
<p>Durante a construção do site, teremos uma pessoa para fazer a revisão das funcionalidades e detectar erros e bugs dos códigos com relação à pagina.</p>

<h2><strong>HTML</strong></h2>
<p>HTML será responsável por toda a estrutura de código (esqueleto) do site.</p>
<p>A partir da codificação em HTML, será adicionado links, imagens fixas (sobre nós) e interligação com as outras linguagens de programação.
<h2><strong>CSS</strong></h2>
<p>O CSS será responsável pela estilização do site utilizando as cores da palheta, alinhando textos, imagens e vídeos com precisão.
<h2><strong>Javascript</strong></h2>
O Javascript será responsáavel por dar funcionalidades ao site, como o menu hambúrguer, vídeos e imagens com transição, animações, etc.; fornecendo uma página web lúdica e mais interativa com o público.</p>
<p>Estará diretamente linkado com outras linguagens para fazer atualizações em tempo real, e facilitar o back-ending.</p>
<h2><strong>SQL Sever</strong></h2>
<p>Será a linguagem de programação utilizada para a criação de um banco de dados ordenado para registro de informações e resgate das mesmas, deixando os novos usuários seguros sem perder as informações e o progresso do curso, enquanto os que estão querendo sair, podendo excluir sua conta do banco de dados sem precisar acessá-lo diretamente.
<p>Fará conexão direta com o HTML e Javascript para registro e atualizações e manutenções do sistema.</p>
<h2>Instrução</h2>
<p>Os códigos serão feitos e executados seguindo as instruções da administração, sujeito a revisão, manutenção, exclusão e criação de um novo projeto. A estilização do site, seguirá as instruções (palheta de cores, logo, filmagens, fotos e videos) do Marketing.</p>
<p>O prazo máximo de entrega do site será a última quinta-feira antes da apresentação para a banca.</p>
<p>Conto com a ajuda de todos os colaboradores para entregarmos o melor resultado possível em 3 meses!</p>
